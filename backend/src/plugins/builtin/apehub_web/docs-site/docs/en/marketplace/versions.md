# Versions & Review

```text
Draft → AI Analysis → Submit → Under Review → Approved → Publish
  ↑       ↓                      ↓
  └── Analysis failed / Rejected ←──┘
```

## Review & Publish Are Separate

When reviewing, admins can inspect the version file tree, source preview, static risk hints, developer profile and review history. The platform service-fee percentage is set on the first approval. Approval does not auto-publish — an explicit "Publish" action is required.

After a new version is published, older versions remain in the version tree marked as historical. The marketplace shows the current published version by default; buyers can keep downloading all published versions.

## Version Edit Boundaries

Draft, analysis-failed and rejected versions can be edited. Versions under review, approved or already published cannot be overwritten directly; you must create a new version submission so that reviewed and sold content remains traceable.

## Version Entitlement

A single purchase creates a permanent entitlement for the plugin — buyers can download all current and future published versions. After a refund, the entitlement is revoked and further downloads are denied.
