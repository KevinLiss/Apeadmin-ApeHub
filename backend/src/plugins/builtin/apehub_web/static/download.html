安装说明

三步完成部署（Python 版）

1下载安装包

点击上方「立即下载」获取最新版 ZIP 安装包，也可在全部版本中选择历史版本。

2上传到服务器

将安装包上传至 ApeAdmin 服务器，然后在管理后台「系统管理 → 版本更新」中选择该 ZIP 包并一键更新。

# 也可通过命令行部署 pip install -r requirements.txt python -m uvicorn src.main:app --host 0.0.0.0 --port 80

3完成部署

服务启动后访问 http://你的域名/admin/，默认账号 admin，首次登录后请及时修改密码。更多细节见Python 技术文档。

1下载安装包

点击上方「立即下载」获取 Go 版 ZIP 安装包。Go 版为单二进制部署，无需 Python 运行时。

2编译并启动

将 ZIP 解压后，编译并运行单个可执行文件，默认端口 8001：

# 编译（需要 Go 1.21+） go build ./... # 启动（默认 SQLite，端口 8001） go run cmd/server/main.go

3配置与访问

生产环境请修改 configs/config.yaml 中的 jwt.secret 并设置 debug=false。访问 http://localhost:8001，默认账号 admin / admin123。更多细节见Go 技术文档。
